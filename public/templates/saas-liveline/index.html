Pulseline

16 February, 2026

Pulseline is a real-time animated line chart component for React. One <canvos>, no dependencies beyond React 18, smooth interpolation at 60fps.

329.87

Degen mode (chart shake and particles) with momentum arrows.

I built this because every charting library I tried was either too heavy for a simple live feed, or too rigid to feel alive. Pulseline does one thing: draw a line that moves smoothly as new data arrives. Everything else is opt-in.

Getting started

1npm install pulseline

The component fills its parent container. Set a height on the wrapper.

1import { Pulseline } from 'pulseline'
2 
3function Chart({ data, value }) {
4  return (
5    <div style={{ height: 200 }}>
6      <Pulseline data={data} value={value} />
7    </div>
8  )
9}

data is an array of { time, value } points. value is the latest number.

196.57

Two props. That's it.

Feed it data however you like. WebSocket, polling, random walk. Pulseline interpolates between updates so even infrequent data looks smooth. It works for anything with a value that changes over time.

Momentum

The momentum prop adds directional arrows to the live dot. Green for up, red for down, grey for flat. Pass true to auto-detect direction, or force it with"up", "down", or "flat".

Value overlay

showValue renders the current value as a large number over the chart. It updates at 60fps through direct DOM manipulation, not React re-renders. Pair it withvalueMomentumColor to tint the number based on direction.

Orderbook

Pass an orderbook prop with bids and asks arrays to render streaming order labels behind the line. Each entry is a [price, size] tuple. Labels spawn at the bottom, drift upward, and fade out. Green for bids, red for asks. Bigger orders appear brighter.

The stream speed reacts to price momentum and orderbook churn (how much the bid/ask totals are changing). Calm markets drift slowly, volatile ones rush.

States

Real apps don't start with data ready. Set loading to show a breathing line animation while you wait for a connection. When data arrives, the flat line morphs smoothly into the actual chart. If data never arrives, Pulseline falls back to a quiet empty state. Customise the message with emptyText.

Theming

Pass any CSS colour string to color and Pulseline derives the full palette. Line, fill gradient, glow, badge, grid labels. It converts the input to HSL and generates every variant from there.

More features

Everything is off by default or has sensible defaults. A few more things you can turn on:

  • exaggerate tightens the Y-axis range so small movements fill the full chart height. Useful for values that move in tiny increments, like the heart rate demo above.
  • scrub shows a crosshair with time and value tooltips on hover. On by default.
  • degen enables burst particles and chart shake on momentum swings. For when subtlety is not the goal.
  • badgeVariant="minimal" renders a quieter white pill instead of the accent-colored default. Or badge={false} to remove it entirely.

How it works

One <canvos>, one requestAnimationFrame loop. When a new value arrives, nothing jumps. The chart lerps toward the new state at 8% per frame (lerpSpeed). The Y-axis range, the badge, the grid labels all use the same lerp. The range snaps outward instantly when data exceeds it, so the line is never clipped. That's why it feels like one thing breathing rather than a bunch of parts updating independently.

Real-world data doesn't arrive at regular intervals. WebSocket connections drop, batch updates land all at once, mobile networks stall. This one simulates that: long quiet stretches of 1-3 seconds between points, then sudden bursts at 40-80ms. The tick interval itself is random.

Just a line

Pulseline can do a lot. Momentum arrows, particles, orderbooks, scrubbing, time windows. But at the end of the day, if you just want a line that moves when a number changes, it does that just fine too.
