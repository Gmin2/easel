Harbor.com provides information and resources about the fundamentals of the decentralised non-custodial liquidity protocol called the Harbor Protocol, comprised of open-source self-executing smart contracts that are deployed on various permissionless public blockchains, such as Ethereum (the "Harbor Protocol" or the "Protocol"). Harbor Labs does not control or operate any version of the Harbor Protocol on any blockchain network.
